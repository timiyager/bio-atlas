Атлас биомолекул — сайт-приложение (PWA)

Как поставить в виде приложения:
- Android (Chrome): открыть ссылку → меню ⋮ → Установить приложение / Добавить на главный экран
- iPhone (Safari): открыть ссылку → Поделиться → На экран "Домой"
- ПК (Chrome/Edge): значок установки в адресной строке.
После первого открытия атлас работает без интернета. Прогресс сохраняется в памяти вашего устройства. Если захотите перенести на другое устройство:
Прогресс → Сохранить копию (файл .json) → на новом устройстве "Загрузить копию"
