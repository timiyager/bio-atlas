Атлас биомолекул — сайт-приложение (PWA)

Как выложить бесплатно (нужен только аккаунт GitHub, ~5 минут):
1. github.com → New repository → имя, например, bio-atlas → Public → Create.
2. «uploading an existing file» → перетащите ВСЁ содержимое этой папки (index.html, sw.js, manifest.webmanifest, папку icons, .nojekyll) → Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch: main, / (root) → Save.
4. Через 1–2 минуты сайт откроется по адресу https://<ваш-логин>.github.io/bio-atlas/

Как ученикам поставить «как приложение»:
• Android (Chrome): открыть ссылку → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
• iPhone (Safari): открыть ссылку → «Поделиться» → «На экран „Домой“».
• Компьютер (Chrome/Edge): значок установки в адресной строке.
После первого открытия атлас работает и без интернета.

Прогресс хранится на устройстве ученика. Перенести на другое устройство:
«Прогресс» → «Сохранить копию» (файл .json) → на новом устройстве «Загрузить копию».

Обновить атлас: загрузите новый index.html в тот же репозиторий — у учеников он подтянется при следующем открытии с интернетом.
